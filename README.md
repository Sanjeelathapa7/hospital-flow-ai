# HospitalFlow AI

## Multi-Agent Hospital Patient Flow and Bed Management System

**Module:** CN7050 – Intelligent Systems  
**Programme:** MSc Artificial Intelligence  
**University:** University of East London  
**Project Status:** Under Development

## Project Overview

HospitalFlow AI is a proposed multi-agent intelligent system designed to support hospital patient flow, bed allocation, discharge prediction and operational coordination.

## Objectives

- Prioritise patient admissions using recorded clinical urgency.
- Recommend suitable hospital beds.
- Predict hospital length of stay using machine learning.
- Identify operational bottlenecks.
- Support human-in-the-loop decision-making.

## Agent Architecture

1. Admission Prioritisation Agent
2. Bed Allocation Agent
3. Discharge Prediction Agent
4. Coordination and Human Approval Agent

## Dataset

Auric Grid Synthetic Hospital Operations Environment (E3.H2), available through Hugging Face.

The dataset contains 50,000 synthetic patients and approximately 1.55 million hospital operational events.

Dataset access is restricted. Raw dataset files are not included in this repository.

## Proposed Technologies

Python, Pandas, NumPy, Scikit-learn, LangGraph, SQLite, Streamlit and Plotly.

## Disclaimer

This project is an academic simulation using synthetic data. It is not intended for clinical decision-making or real patient care.
